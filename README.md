# Ronu
Plataforma que gera dietas personalizadas para praticantes de jiu-jitsu e outras artes marciais, usando IA

## Fontes dos dados nutricionais

- NEPA/UNICAMP. Tabela Brasileira de Composição de Alimentos (TACO). 4ª ed. rev. e ampl. Campinas: NEPA/UNICAMP, 2011.
- U.S. Department of Agriculture, Agricultural Research Service. FoodData Central (SR Legacy). https://fdc.nal.usda.gov
- IBGE. Pesquisa de Orçamentos Familiares 2008-2009: Tabela de Medidas Referidas para os Alimentos Consumidos no Brasil. Rio de Janeiro: IBGE, 2011.

Detalhes, licenças e método em [docs/fontes-nutricionais.md](docs/fontes-nutricionais.md).
